# Perangkat Kerja Dokter Sp.KKLP

Alat bantu kedokteran keluarga layanan primer, bisa dipakai di ponsel maupun komputer.

**Buka:** https://dokterren.github.io/kklp-tools/

| Alat | Fungsi |
|---|---|
| **Asesmen Keluarga** |  |
| [Genogram, Peta Keluarga & Ekomap](https://dokterren.github.io/kklp-tools/genogram.html) | Genogram dengan simbol standar, peta keluarga, ekomap, lembar presentasi kasus A4; unduh PNG/SVG/PDF |
| [APGAR, SCREEM & Siklus Hidup](https://dokterren.github.io/kklp-tools/asesmen-keluarga.html) | APGAR Keluarga (hingga 3 responden), SCREEM, siklus hidup keluarga (Duvall); ringkasan A4 |
| **Asesmen Pasien dan Pelaku Rawat** |  |
| [Indeks Kesehatan Menyeluruh](https://dokterren.github.io/kklp-tools/lmwphi.html) | Kuesioner LMWPHI v4 (terjemahan Bahasa Indonesia) dengan skor otomatis enam pilar, grafik, dan laporan PDF |
| [Indeks Barthel](https://dokterren.github.io/kklp-tools/barthel.html) | ADL versi 0–20 dengan kategori ketergantungan |
| [Kesiapan Merawat](https://dokterren.github.io/kklp-tools/kesiapan-merawat.html) | Preparedness for Caregiving Scale untuk pelaku rawat |
| [Kepatuhan Minum Obat](https://dokterren.github.io/kklp-tools/kepatuhan-obat.html) | Morisky, Green & Levine 4 butir |
| **Intervensi Gaya Hidup** |  |
| [Resep Gaya Hidup](https://dokterren.github.io/kklp-tools/resep-gaya-hidup.html) | Perubahan 6 pilar yang disepakati dan kalender centang 30 hari |
| [Rencana Aksi Perubahan](https://dokterren.github.io/kklp-tools/rencana-aksi.html) | Hasil konsultasi bergaya coaching untuk satu pilar: kondisi, target, langkah, waktu kontrol |
| **Koordinasi Perawatan** |  |
| [Konferensi Kasus Terpadu](https://dokterren.github.io/kklp-tools/konferensi-kasus.html) | Rencana perawatan terpadu pasien rawat inap (2 halaman) dan ringkasan bahasa sederhana untuk keluarga |
| [Rekonsiliasi Obat](https://dokterren.github.io/kklp-tools/rekonsiliasi-obat.html) | Obat sebelum masuk, saat masuk, rawat inap, dan saat pulang; telaah polifarmasi; A4 lanskap |
| **Catatan untuk Pasien** |  |
| [Rencana Sehat Saya](https://dokterren.github.io/kklp-tools/rencana-sehat.html) | Isi rencana perawatan pasien di layar, cetak atau unduh PDF A4 (2 halaman) |
| [Catatan Pemantauan Metabolik](https://dokterren.github.io/kklp-tools/pemantauan-metabolik.html) | Lembar 15 hari dengan identitas, jadwal, dan target pasien tercetak; bisa juga dicetak polos |
| **Materi Edukasi Pasien** | |
| [Leaflet Edukasi](https://dokterren.github.io/kklp-tools/edukasi/) | Leaflet A4 siap cetak: 6 pilar gaya hidup sehat, indeks glikemik makanan, perawatan stroke di rumah; nama pasien dan catatan dokter bisa diisi |

## Privasi data pasien
Situs ini tidak mempunyai server. Semua data yang diketik hanya tersimpan di browser perangkat pengguna dan tidak pernah dikirim ke mana pun. Gunakan tombol simpan file data (.json) untuk mencadangkan atau memindahkan data ke perangkat lain.
